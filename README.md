# E-COMMERCE-CLOTHING-WEBSITE

# 🛍️ E-Commerce Clothing & Accessories Website

This is a fully responsive E-commerce website for a fictional clothing and accessories brand. Built using **HTML**, **CSS**, and **JavaScript**, it showcases various products with an interactive and visually appealing user interface.

## 🚀 Features

- 🖼️ Homepage with banner and promotional sections
- 🧥 Product listings with images, names, prices, and categories
- 🔍 Product search and filter functionality
- 🛒 Add to Cart functionality with dynamic updates
- 📱 Responsive design for mobile, tablet, and desktop views
- 🔁 Smooth transitions and hover effects
- 🌙 Optional dark mode toggle (if implemented)

## 📁 Technologies Used

- **HTML5** – Structure and semantic layout
- **CSS3** – Styling, animations, and responsive design
- **JavaScript (Vanilla JS)** – Interactivity and cart functionality
